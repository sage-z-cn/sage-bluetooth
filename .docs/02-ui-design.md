# UI 设计文档

## 1. 设计原则

- **紧凑高效**：主窗口尺寸固定为 400x600，信息密度高，操作路径短
- **视觉层次清晰**：通过颜色、图标、间距区分功能区域
- **状态即时反馈**：所有操作（扫描、连接、断开）都有明确的状态指示
- **托盘优先**：用户主要通过托盘图标与工具交互，窗口为辅助操作面板

## 2. 系统托盘设计

### 2.1 托盘图标状态

| 状态 | 图标 | 提示文本 (ToolTip) |
|-----|------|-------------------|
| 蓝牙关闭 | `bluetooth_off.png` | Sage Bluetooth - 蓝牙已关闭 |
| 蓝牙开启，未连接 | `bluetooth_on.png` | Sage Bluetooth - 蓝牙已开启 |
| 蓝牙开启，已连接 | `app.ico` (彩色高亮) | Sage Bluetooth - 已连接: {设备名} |
| 扫描中 | 动态旋转图标 | Sage Bluetooth - 正在扫描... |

### 2.2 托盘交互行为

| 操作 | 行为 |
|-----|------|
| 左键单击 | 切换主窗口显示/隐藏。窗口显示位置固定在屏幕右下角（任务栏上方） |
| 右键单击 | 显示上下文菜单 |
| 左键双击 | 同左键单击 |

|-----|---|

| 位置 | 屏幕右下角，紧贴任务栏上方 |
| 边框 | 无边框或细边框 (FramelessWindowHint + 自定义标题栏) |

## 4. 组件详细设计

### 4.1 自定义标题栏 (TitleBar)

```
┌────────────────────────────────────────┐
│ [icon] 应用名称          [蓝牙灯] ─ □ ✕ │
└────────────────────────────────────────┘
```

- **高度**：36px
- **背景色**：`#2D2D2D` (深色主题)
- **文字颜色**：`#FFFFFF`
- **蓝牙状态灯**：
  - 绿色 `#4CAF50`：蓝牙已开启
  - 红色 `#F44336`：蓝牙已关闭
  - 黄色 `#FFC107`：扫描中/连接中
- **按钮**：最小化（隐藏窗口）、关闭（隐藏窗口，非退出）
- **拖拽**：按住标题栏可拖动窗口

### 4.2 控制面板 (ControlPanel)

```
┌────────────────────────────────────────┐
│ [  🔵 开启蓝牙  ] [  🔄 刷新  ] [  ✕ 断开  ]│
└────────────────────────────────────────┘
```

- **高度**：52px
- **布局**：水平排列，等宽按钮
- **按钮状态**：
  - `开启蓝牙`：蓝牙关闭时启用，开启后变为 `关闭蓝牙`
  - `刷新`：始终启用，点击后变为禁用状态并显示加载动画，扫描完成后恢复
  - `断开`：无连接时禁用，有连接时启用

### 4.3 设备列表 (DeviceListWidget)

基于 `QListWidget` 或 `QListView` + 自定义 `QStyledItemDelegate` 实现。

**列表项结构：**

```
┌────────────────────────────────────────┐
│ ┌────┐ ┌─────────────────────────────┐ │
│ │icon│ │ 设备名称 (加粗)              │ │
│ │    │ │ 地址: XX:XX:XX:XX:XX:XX     │ │

└────────────────────────────────────────┘
```

- **项高度**：64px
- **图标尺寸**：40x40px
- **选中样式**：左侧蓝色边框 `#2196F3`，背景色 `#E3F2FD`
- **悬停样式**：背景色 `#F5F5F5`

**空状态：**
```
┌────────────────────────────────────────┐
│                                        │
│           📡                           │
│      未发现蓝牙设备                     │
│    点击"刷新"按钮开始扫描               │
│                                        │
└────────────────────────────────────────┘
```

**扫描中状态：**
```
┌────────────────────────────────────────┐
│                                        │
│       🔄 (旋转动画)                     │
│      正在扫描附近设备...                │
│      已发现 3 个设备                    │
│                                        │

```

```
│  名称:        AirPods Pro              │
│  地址:        XX:XX:XX:XX:XX:XX        │

│  厂商:        Apple Inc.               │
│  型号:        AirPods Pro              │
│  序列号:      --                       │
│  固件版本:    5B58                     │
│  电量:        80% 🔋                   │
│  信号强度:    -65 dBm  ████████░░      │
│  连接状态:    ✅ 已连接                 │
├────────────────────────────────────────┤
│ [  连接  ] [  配对  ] [  断开  ]       │
```

- **字段标签**：灰色 `#757575`，右对齐

  - `-61 ~ -70` dBm：6 格
  - `-71 ~ -80` dBm：4 格
  - `-81 ~ -90` dBm：2 格
  - `< -90` dBm：1 格

## 5. 交互流程

### 5.1 窗口弹出/隐藏

```
用户左键点击托盘图标
        │
        ▼
┌───────────────┐
│ 窗口是否可见?  │
└───────┬───────┘
   是 /   \ 否
    ▼       ▼
  隐藏    计算位置
  窗口    (屏幕右下角)
            │
            ▼
         显示窗口
         置顶
```

**窗口位置计算（右下角）：**
```python
screen = QApplication.primaryScreen().geometry()
window_x = screen.width() - window_width - margin_right
window_y = screen.height() - window_height - taskbar_height - margin_bottom
```

### 5.2 失去焦点自动隐藏

```python
def eventFilter(self, obj, event):
    if event.type() == QEvent.WindowDeactivate:
        self.hide()  # 失去焦点时隐藏窗口
    return super().eventFilter(obj, event)
```

> 可通过设置选项关闭此行为，允许窗口常驻。

### 5.3 设备选择 → 详情展示

```
用户点击列表项
        │
        ▼
┌───────────────┐
│ 获取设备数据   │
│ (从内存模型)   │
└───────┬───────┘
        ▼
┌───────────────┐
│ 更新详情面板   │
│ (字段 + 按钮)  │
└───────┬───────┘
        ▼
┌───────────────┐
│ 设备已连接?    │
└───────┬───────┘
   是 /   \ 否
    ▼       ▼
 显示断开   显示连接+配对
```

## 7. 动画与过渡

| 动画 | 实现方式 | 时长 |
|-----|---------|------|
| 窗口弹出 | QPropertyAnimation (pos + opacity) | 200ms |
| 窗口隐藏 | QPropertyAnimation (pos + opacity) | 150ms |
| 扫描旋转图标 | QMovie / CSS rotation | 循环 |
| 按钮加载状态 | QMovie 在按钮内 | 循环 |
| 列表项添加 | 淡入 | 150ms |
| 信号强度条变化 | 宽度过渡 | 300ms |

| 断开中 | 黄色 | "关闭蓝牙" | 禁用 | 禁用 | 禁用 | 显示"断开中..." |
