# UI 设计文档

## 1. 设计原则

- **紧凑高效**：主窗口尺寸固定为 400x600，信息密度高，操作路径短
- **视觉层次清晰**：通过颜色、图标、间距区分功能区域
- **状态即时反馈**：所有操作（扫描、连接、断开）都有明确的状态指示
- **托盘优先**：用户主要通过托盘图标与工具交互，窗口为辅助操作面板

## 2. 系统托盘设计

### 2.1 托盘图标状态

| 状态 | 图标 | 提示文本 (ToolTip) |
|-----|------|-------------------|
| 蓝牙关闭 | `bluetooth_off.png` | Sage Bluetooth - 蓝牙已关闭 |
| 蓝牙开启，未连接 | `bluetooth_on.png` | Sage Bluetooth - 蓝牙已开启 |
| 蓝牙开启，已连接 | `app.ico` (彩色高亮) | Sage Bluetooth - 已连接: {设备名} |

### 2.2 托盘交互行为

| 操作 | 行为 |
|-----|------|
| 左键单击 | 切换主窗口显示/隐藏。窗口显示位置固定在屏幕右下角（任务栏上方） |
| 右键单击 | 显示上下文菜单 |
| 左键双击 | 同左键单击 |

### 2.3 托盘右键菜单

### 3.1 窗口规格

| 属性 | 值 |
|-----|---|
| 尺寸 | 400 x 600 (固定大小，不可调整) |
| 位置 | 屏幕右下角，紧贴任务栏上方 |

## 4. 组件详细设计

### 4.1 自定义标题栏 (TitleBar)

```
┌────────────────────────────────────────┐
│ [icon] 应用名称          [蓝牙灯] ─ □ ✕ │
└────────────────────────────────────────┘
```

- **高度**：36px
- **背景色**：`#2D2D2D` (深色主题)
- **文字颜色**：`#FFFFFF`
- **蓝牙状态灯**：
  - 绿色 `#4CAF50`：蓝牙已开启
  - 红色 `#F44336`：蓝牙已关闭
  - 黄色 `#FFC107`：扫描中/连接中
- **按钮**：最小化（隐藏窗口）、关闭（隐藏窗口，非退出）
- **拖拽**：按住标题栏可拖动窗口

### 4.2 控制面板 (ControlPanel)

```
┌────────────────────────────────────────┐
│ [⚪ OFF] 蓝牙            [🔄 刷新]     │
└────────────────────────────────────────┘
```

- **高度**：52px
- **布局**：水平排列，左侧为蓝牙 Switch 开关，右侧为刷新按钮
- **蓝牙 Switch**：
  - 采用 Toggle Switch 样式（滑动开关），OFF/ON 双态切换
  - 关闭态（OFF）：灰色滑块，无背景高亮
  - 开启态（ON）：绿色滑块，背景高亮
  - 标签文字：根据当前状态显示 "蓝牙 OFF" 或 "蓝牙 ON"
  - 禁用态：当连接中/断开中/扫描中时，Switch 禁用，不可切换
- **刷新按钮**：
  - 始终位于面板右侧，固定宽度
  - 点击后变为禁用状态并显示加载动画，扫描完成后恢复

### 4.4 设备详情面板 (DeviceDetailWidget)

**显示/隐藏规则：**

| 场景 | 详情面板状态 | 说明 |
|------|------------|------|
| 默认启动 | 隐藏 | 设备列表占满窗口高度 |
| 点击设备条目选中 | 滑入展开 | 从底部向上展开，列表高度自动收缩 |
| 再次点击同一设备 | 保持展开 | 详情内容不变 |
| 点击其他设备 | 切换内容 | 面板保持展开，内容平滑切换 |
| 执行刷新操作 | 自动收起 | 面板向下滑出隐藏，取消选中状态 |
| 蓝牙关闭 | 自动收起 | 面板隐藏，恢复默认布局 |

**未展开时（默认）：** 详情面板完全隐藏，设备列表占据全部高度。

**展开后（已选中设备）：**

- **字段标签**：灰色 `#757575`，右对齐

  - `-81 ~ -90` dBm：2 格
  - `< -90` dBm：1 格

## 5. 交互流程

### 5.1 窗口弹出/隐藏

```
用户左键点击托盘图标
        │
        ▼
┌───────────────┐
│ 窗口是否可见?  │
└───────┬───────┘
   是 /   \ 否
    ▼       ▼
  隐藏    计算位置
  窗口    (屏幕右下角)
            │
            ▼
         显示窗口
         置顶
```

**窗口位置计算（右下角）：**
```python
screen = QApplication.primaryScreen().geometry()
window_x = screen.width() - window_width - margin_right
window_y = screen.height() - window_height - taskbar_height - margin_bottom
```

### 5.2 失去焦点自动隐藏

```python
def eventFilter(self, obj, event):
    if event.type() == QEvent.WindowDeactivate:
        self.hide()  # 失去焦点时隐藏窗口
    return super().eventFilter(obj, event)
```

> 可通过设置选项关闭此行为，允许窗口常驻。

### 5.4 设备操作按钮（列表条目内）

根据设备当前配对与连接状态，列表条目右侧的操作按钮组动态变化：

```
┌─────────────────────────────────────────────────────┐
│ 设备状态          │  配对/连接按钮  │  断开  │  删除  │
├───────────────────┼───────────────┼────────┼────────┤
│ 未配对            │  [配对] (蓝)   │  -     │  [删除]│
│ 已配对·未连接     │  [连接] (蓝)   │  -     │  [删除]│
│ 已连接            │  -            │ [断开] │  [删除]│

│ 断开中            │  -            │ 断开中 │  [删除]│

```

> `配对` 和 `连接` 合并为一个多功能按钮，根据设备配对状态动态切换文本和行为。

## 7. 动画与过渡

| 动画 | 实现方式 | 时长 |
|-----|---------|------|
| 窗口弹出 | QPropertyAnimation (pos + opacity) | 200ms |
| 窗口隐藏 | QPropertyAnimation (pos + opacity) | 150ms |
| 扫描旋转图标 | QMovie / CSS rotation | 循环 |
| 按钮加载状态 | QMovie 在按钮内 | 循环 |
| 列表项添加 | 淡入 | 150ms |
| 信号强度条变化 | 宽度过渡 | 300ms |
| 详情面板展开 | QPropertyAnimation (height, 最大高度变化) + 列表高度联动 | 250ms ease-out |
| 详情面板收起 | QPropertyAnimation (height, 最大高度变化) + 列表高度联动 | 200ms ease-in |
| 详情面板内容切换 | 淡出旧内容 → 更新 → 淡入新内容 | 150ms + 150ms |
| 删除确认对话框弹出 | 淡入 + 缩放 | 200ms |
| 删除确认对话框关闭 | 淡出 | 150ms |
| 设备从列表移除 | 淡出 + 高度收缩 | 200ms |
